# SUNAI Product Direction

## Audience
SUNAI serves English learners across all levels:
- Beginner: A1
- Elementary: A2
- Intermediate: B1
- Upper-intermediate: B2
- Advanced: C1-C2

The experience should adapt to the learner rather than forcing every user through the same path.

## Learning pillars
1. Vocabulary — useful words, collocations, spaced review.
2. Grammar — clear explanations followed by practice.
3. Listening — short audio-based comprehension tasks.
4. Speaking — guided prompts and pronunciation practice.
5. Reading — level-appropriate passages and comprehension.
6. Writing — guided writing with AI feedback.
7. Communication — practical conversations and role-based scenarios.

## Core product loop
Assess → recommend a path → learn a small concept → practice → receive feedback → review weak areas → track progress.

## Level model
Each level contains:
- Units
- Lessons
- Practice sets
- Review sessions
- Checkpoints

## Exercise types
- Multiple choice
- Fill in the blank
- Sentence ordering
- Matching
- Listening comprehension
- Vocabulary recall
- Short-answer writing
- Speaking prompts

## AI features
- AI Tutor: explain, hint, and converse.
- AI Speaking Coach: feedback on clarity, pronunciation, vocabulary, and grammar.
- AI Writing Coach: actionable corrections and explanations.
- Personalized recommendations based on learning history.

## UX principles
- Short sessions.
- Immediate feedback.
- Visible progress.
- Encouraging, never overwhelming.
- Mobile-first responsive design.
- Accessibility and readable typography.

## Initial milestone
Build the learning architecture and lesson experience before connecting real AI APIs or persistent user data.
